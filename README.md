# Guías de administración de sistemas

Guías paso a paso de servicios que he montado en laboratorio, con los comandos,
la configuración que elegí y por qué.

| Guía | De qué va |
|---|---|
| [WSUS](wsus.md) | Actualizaciones de Windows centralizadas para un dominio, con grupos de equipos, aprobaciones y directivas de grupo |
| [Zabbix](zabbix.md) | Monitorización de servidores Linux: servidor con MySQL y Apache, agente, inventario automático y gráficas |

Las contraseñas y nombres de los ejemplos son genéricos: hay que cambiarlos por
los propios.
